How to talk to Sobot

  • "Hey Sobot" — wake word, activates hands-free listening
  • Tap the orb — start / stop voice input anytime
  • Mic button in the transcript — voice input from the chat
  • Type a command in the transcript input

Voice commands

  • 🔊 Volume — "volume up", "set volume to 80 percent", "mute / unmute"
  • ☀️ Brightness — "brightness up", "set brightness to 50 percent"
  • 📸 Screenshot — "take a screenshot"
  • 📋 Clipboard — "copy this", "copy to clipboard"
  • 🌐 Web search — "search for the tallest mountain"
  • 🗔 Apps & media — "open calculator", "play music", "next song"
  • 🔒 Lock screen — "lock the screen"
  • 🖱️ Cursor — "enable cursor", "disable cursor"
  • 🖥️ Camera — "show camera", "hide camera"
  • 💬 Transcript — "clear chat", "show chat", "hide chat"

  • Pinch (thumb + index) — left click
